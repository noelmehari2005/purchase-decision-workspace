# Wireframe sources

These HTML fragments were created during planning and reviewed interactively in chat:

- [Original journey](laptop-decision-wireframe.html)
- [Grouped comparison](laptop-comparison-wireframe.html)
- [Import review](laptop-import-review.html)

They are archived design-preview sources, not standalone production pages or the chosen frontend implementation. They use fictional data and host-provided preview behavior. No real import, account, database, or financial recommendation is connected.

The written requirements supersede limitations in these previews. Examples: the original savings screen does not implement calendar contribution dates; the import prototype requires a configuration description; comparison importance controls/ranking are incomplete; the full account/deletion flow is not represented. HTML preview state must never be used to collect real financial data.
